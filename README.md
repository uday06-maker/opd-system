# Hospital OPD Queue Management System

A PHP + MySQL web application for managing hospital outpatient department queues.

## Tech Stack
- PHP (Backend)
- MySQL (Database)
- Bootstrap 5 (UI)
- XAMPP (Local Server)

## Features
- Online token booking
- Live queue display
- Doctor dashboard
- Admin panel
- Role-based access (Admin / Doctor / Patient)

## Setup
1. Clone repo into `htdocs/opd-system`
2. Start Apache + MySQL in XAMPP
3. Import `opd_system.sql` in phpMyAdmin
4. Visit `http://localhost/opd-system`
